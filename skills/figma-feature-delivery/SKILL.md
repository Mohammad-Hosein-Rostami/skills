# Figma Feature Delivery (orchestrator)

Thin phase runner. **Load child skills** — do not re-implement their bodies here.

## Goal

Pixel-perfect desktop UI (1530×920), exact Figma flows (not similar peers), precise API integration, careful responsive ownership, and a **screenshot → diff → fix → re-diff** loop until grid + list + overlays + kind-specific tabs are solid.

## Context the user must provide

Goal · section · app route · code path · Figma URL(s)/node-ids · notes · API notes · mock-api path · peer path (**wiring only**) · new route? · mobile/tablet Figma frames?

## Non-negotiables

- Parity size **1530×920** DSF 1 — necessary, **never sufficient** alone
- **Exact Figma** (`figma-exact-not-similar`) — no peer UI substitution, no skipped micro-details
- **Responsive + grids** (`figma-responsive-ownership` + `mui-layout-grid`) — full matrix required
- Responsive evidence must include top viewport + full-page (+ required scroll coverage) at each width
- Wide desktop checks are mandatory (**1920 and 2400**), not only <=1530
- **Absolute safety** (`figma-absolute-layout-safety`) whenever Figma uses absolute/fixed/overhang
- **API sync** (`mock-api-openapi-sync`) — schema.md, codegen, revert local URLs
- **Screenshot re-diff** until grid + list + overlay match Figma (not “feels close”)
- No GraphQL · no Tailwind · no `as` to hide types · no hand-edit hey-api-client
